# tools/ — renderers

A renderer turns content JSON into page templates so that a family of pages
(nine services, nine solutions, eight blog posts …) is written once as a
template and stamped out per item.

## Convention

- File name: `tools/render_<family>.py`. Python 3, standard library only.
- `build.py` runs **every** `tools/render_*.py` before it processes pages, in
  sorted order, with the same interpreter (`sys.executable`) and the repo root
  as the working directory. Renderers that do not exist are simply skipped.
- A renderer **reads** `content/*.json` and **writes** page templates into
  `src/pages/**` (for example `src/pages/services/casting.html`). It never
  writes to `dist/`, never edits another agent's files, and must be
  idempotent — running it twice gives the same output.
- The files it writes are ordinary page templates: they may start with
  `<!-- title: … -->` / `<!-- description: … -->` meta comments and use every
  placeholder `build.py` understands (`{{include:…}}`, `{{content:…}}`,
  `{{page.…}}`, `{{drawing}}`, `{{panel:…}}`). Prefer emitting
  `{{content:services.items.3.body}}` references over copying text into the
  template so the JSON stays the single source of truth.
- Exit code 0 on success. A non-zero exit is reported by `build.py` as a
  warning; the build continues with whatever pages exist.
- Print one line per file written, e.g. `wrote src/pages/services/casting.html`.
- Generated templates should carry a first line
  `<!-- generated by tools/render_services.py — edit content/services.json -->`
  (after the meta comments) so nobody edits them by hand.

## Minimal example

```python
#!/usr/bin/env python3
import json
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
items = json.loads((ROOT / "content" / "services.json").read_text())["items"]
out_dir = ROOT / "src" / "pages" / "services"
out_dir.mkdir(parents=True, exist_ok=True)
for i, item in enumerate(items):
    page = f"""<!-- title: {item['title']} — hypjam -->
<!-- description: {item['summary']} -->
<!-- nav: light -->
<!-- nav-fill: bg-white -->
<!-- generated by tools/render_services.py — edit content/services.json -->
{{{{include:partials/head.html}}}}
{{{{include:partials/nav.html}}}}
<main class="bg-white">
  <h1 class="svc-title">{{{{content:services.items.{i}.title}}}}</h1>
</main>
{{{{include:partials/footer.html}}}}
{{{{include:partials/scripts.html}}}}
"""
    target = out_dir / f"{item['slug']}.html"
    target.write_text(page, encoding="utf-8")
    print("wrote", target.relative_to(ROOT))
```

Other tools (checkers such as `check_drawing.py`, one-off measurers) live here
too; only files matching `render_*.py` are run by the build.
